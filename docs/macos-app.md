# MacKit App 使用说明

App 支持 macOS 14+ 与 Apple Silicon。打开 DMG，将 Tianli MacKit 拖到 Applications，再从应用程序打开。它使用 Developer ID 签名并经 Apple 公证。

## 安装配置

1. 选 Developer 通用预设，或 Tianli 个人习惯预设，再选组件。
2. 点击“预览配置变化”。App 会将内置配置准备到 `~/.local/share/mackit`，列出新建和需要备份的文件。此时不会替换应用配置。
3. 在软件与依赖卡片安装缺少的软件。Homebrew 缺失时，点击“安装 Homebrew”下载官方包，并在系统安装器完成。MacKit 不读取管理员密码。
4. 点击“备份并安装配置”，确认列表后安装。已有文件或软链被保存在 `~/.local/state/mackit`。
5. 重新打开终端及相关应用。桌面权限由系统与各应用引导；yabai/skhd 不自动安装或启动。

已有 CLI 安装会继续使用原来的配置源。App 不会覆盖源文件的个人修改。更换预设前，按从新到旧的顺序恢复已有安装；取消勾选只表示本次不处理该组件，不卸载以前安装的配置。

## 查询、编辑与恢复

“快捷键”按用途、键名和路径搜索。编号功能是 `V` 选行后依次按空格 n l。目录来自发行包内的原生键位声明；修改键位源后，维护者应重新生成索引。它不包含所有插件内建键，也不判断其他 App 是否抢键。

“配置文件”选择入口后读取。修改后点击“备份并保存”。保存前会核对磁盘版本；其他程序已改动时拒绝覆盖。已有文件的保存前副本在 `~/.local/state/mackit/editor-backups`。新文件没有旧版本备份。Hammerspoon 可能在保存配置后立即重载，请确认语法。

“检查与恢复”检查所选组件的源与依赖。安装记录按新到旧排列，恢复时只处理最近仍有效的安装；软件本体与个人覆盖保留，后来替换的新文件不会被静默覆盖。

快捷键：⌘1–4 切页、⌘F 查键、⌘R 刷新、⌘S 保存、⌘Return 预览。进行安装、恢复或编辑保存时，请等待结果再退出。

## 常见问题

- 网络失败：查看软件安装运行记录，修复代理或网络后重试。已安装的软件会被识别并跳过。
- Homebrew / 系统安装器需要密码：输入本机管理员密码，只在系统安装器输入。它与 GitHub、Apple ID 密码不同。
- Karabiner 需要额外授权：通过卡片里的官方安装器完成，再按其引导启用系统扩展与输入监控。
- Neovim 第一次下载插件失败：检查 GitHub 连通性，重新打开并运行 `:Lazy sync`。配置安装成功不代表插件下载完成。
- 配置包更新：先备份自定义修改，查看新版发行说明。App 不会自动覆盖已有源码；Git 安装可继续使用 `mackit update`，压缩包安装需要先安排源目录升级。
- Intel Mac：当前 App 安装包只有 arm64，仍可使用 README 中的 Python CLI。

App 关闭后不保留后台服务。终端软件与桌面工具有各自的进程与权限，不由 MacKit 的退出统一停止。
