THE FIELD GUIDE / 配置手册

忘了按什么？
来这里找。

快捷键、适用模式、配置文件放在一起。从正在使用的原生声明生成。

01 / 找配置

打开 Neovim 的配置

config nvim
mackit edit nvim-keys

前者打开 init.lua，后者打开统一键位表。终端的 config 命令是 mackit edit 的兼容入口。

02 / 行编号

选中行 → 空格 n l

alpha       01_alpha
beta    →   02_beta

按 V 选行，j/k 扩大选区，再依次按空格、n、l。它修改文本内容。

03 / 屏幕行号

number 是显示选项

:set number norelativenumber
mackit edit number

第一行显示绝对行号；加 relativenumber 可显示相对距离。空格 u n / u r 分别切换两种行号。

leader = 空格；C = Ctrl；M = Option；n/x/i/t/o = 普通/可视/插入/终端/操作。tmux 前缀为 Option+s。个人预设的全局键可在 Hammerspoon 菜单中单独开关。
